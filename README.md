# Fizzpop

A website for Fizzpop, a made-up drinks brand I invented so I could practise designing a whole brand and not just one page.

**See it here:** https://zitemcodes.github.io/fizzpop/

## What it does

A home page and a brands page. I designed the logos and the can graphics myself before I wrote any of the code, so the site had something real to show.

## How I built it

HTML and CSS by hand. The images are mine, made in a design app, then exported as PNGs and placed into the layout.
